# Security and privacy

Treat public inference as a bounded service. Defaults are for a few friends, not anonymous internet scale.

- Allowlisted file extensions plus actual decode by allowlisted FFmpeg demuxers (wav/mp3/flac/mov/ogg). No playlists, arbitrary URLs, network protocols or streaming-platform downloads. Content-type headers alone are not trusted.
- Streamed HTTP body and file-byte limits, decode output-duration cap, fixed mono sample rate and bounded decoder runtime. Filenames become printable titles only; disk paths are random and never derived from a user name.
- At most two queued/running jobs per client IP, eight upload attempts/minute, sixty edit/export requests/minute, twelve retained jobs, one inference child. These settings are deliberately conservative. Uvicorn connection limits and a reverse proxy also bound multipart parsing concurrency.
- Edited Score is bounded to 2,000 notes, 1,024-beat onsets, 128-beat individual durations, 16 engraving voices/part and a 2 MB request body. No arbitrary code or paths are accepted. Expensive export is still CPU work: public operators must retain outer CPU/memory/connection limits.
- A new subprocess owns each inference task; timeout/cancel kills that worker. FFmpeg is a separate bounded subprocess. Docker drops capabilities, uses an unprivileged backend user, a read-only root filesystem, bounded tmpfs, CPU, memory and PID caps. This is defense in depth, not a sandbox for untrusted executable plugins.
- Queue state and IP rate buckets are in memory. Job IDs are 256-bit random bearer tokens; anyone with one can access/delete that job until expiry. No listing endpoint. Use TLS; do not share URLs. Avoid access logs with job tokens in production.
- Compressed uploads are deleted after success, audio after failures, all job files on cancel/delete/expiry/shutdown/restart. Cleanup runs every 30 seconds; default TTL is one hour after completion (or creation for abandoned uploads). A server crash can leave disk files in native mode until the next startup; Docker tmpfs disappears with container removal. Disk backups must exclude `data/`.
- CORS is a specific origin allowlist, not authentication. It does not prevent command-line API access. Public deployment needs upstream ingress limits/TLS; optional network access controls are appropriate for a friends-only server.
- Never trust arbitrary `X-Forwarded-For`. Default Compose disables proxy headers. With separate trusted ingress, configure the exact trusted proxy IPs in Uvicorn, and prevent direct external backend access. Otherwise all visitors may share the proxy IP quota.
- Frontend stores no secrets; `VITE_*` values are public. No analytics or external font fetches; system fonts work offline. The Android WebView uses `https://localhost`, which must be explicitly allowed by backend CORS. Native uploads use only configured HTTPS origins, without certificate bypasses.
- Offline score storage is intentional retention of note events/metadata, not original audio. Recovery drafts and library entries can be removed in the UI; clearing browser/app data also removes them. Portable JSON backup import is size/schema validated. The PWA service worker caches only app assets, never inference API responses or audio. Android app-private Filesystem data is indexed by Preferences, backup is disabled, and exported shares use cache-only FileProvider URIs.
- APK release credentials are environment/GitHub Actions secrets, never frontend variables. Keystores are ignored, decoded into ephemeral runner storage and deleted after release builds. Untrusted fork PRs receive no signing secrets. Debug APKs are test artifacts with a separate signing identity.

Report security issues privately to the repository owner before disclosing exploitable details. Review dependency advisories and base-image updates before exposing a deployment; pinned historical ML compatibility packages are not a promise of current vulnerability freedom.
