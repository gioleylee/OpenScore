## Basic Pitch weights

Use only the bundled `basic_pitch/saved_models/icassp_2022/nmp.tflite` from the official PyPI 0.4.0 wheel, under the upstream repository Apache-2.0 license. No third-party rehost, new weights, fine-tuning, paid service or non-commercial-only model is used. There is no separate non-commercial restriction in the selected upstream asset license. Keep the upstream copyright and Apache license when redistributing that wheel/model. The inventory records the actual model SHA-256; the upstream license copy is in `docs/licenses/basic-pitch-LICENSE.txt`.

Sources: [official Basic Pitch](https://github.com/spotify/basic-pitch), [package configuration](https://github.com/spotify/basic-pitch/blob/main/pyproject.toml), [license](https://github.com/spotify/basic-pitch/blob/main/LICENSE), [bundled assets](https://github.com/spotify/basic-pitch/tree/main/basic_pitch/saved_models). Python 3.11 triggers TensorFlow dependencies upstream. Loading the SavedModel proved incompatible with Keras deserialization in this environment; the same wheel's TFLite asset passes the real two-note chord test. No model loading failure is treated as success.

## Alternatives evaluated, not bundled

- [Demucs](https://github.com/facebookresearch/demucs): source is MIT, but upstream is archived and explicitly no longer actively maintained. Separation adds Torch, memory/latency and model-specific provenance review. Deferred; no Demucs model weights redistributed or commercial licensing assumptions made.
- [MuScriptor](https://github.com/muscriptor/muscriptor): promising multi-instrument research reference. No integration or weights included; its specific code/weight license terms, resource needs and CPU performance must be audited before adoption. Its availability does not establish suitability for this small CPU MVP.
- [Song2Sheet](https://github.com/kishormorol/song2sheet): architectural reference for modular audio→notes→notation/tab processing. No source/model copied or bundled. Its claimed accuracy is not a benchmark for this project.
- AutoTabber is an ambiguous project name; the identifiable [AutoTab](https://github.com/namithrao/AutoTab) is a multimodal audio/video research approach, unlike this audio-only service. No package adopted or license assumed from its name.
- [Basic Pitch TS](https://github.com/spotify/basic-pitch-ts): possible future client-only inference; currently not bundled or promised as a fallback.

## Redistribution

MIT applies to this repository's original source. Keep third-party notices for dependencies. FFmpeg's license depends on build flags: run the selected executable with `-L` and `-version` and preserve the corresponding notices/source availability when redistributing images or binaries. Docker uses Debian's FFmpeg package; get corresponding source from [Debian sources](https://sources.debian.org/src/ffmpeg/) for the exact installed version. The Windows imageio bundle reports the [Gyan build](https://www.gyan.dev/ffmpeg/builds/); consult that distributor's build/source details for its version. A subprocess boundary does not waive obligations for distribution of the executable itself.

Dependency maintenance/security must be reviewed before public release and over time. Legacy ML dependencies have a longer compatibility tail than the frontend. `npm audit` reported zero vulnerabilities after updating Vite and OSMD; this is not an audit of the Python stack, OS images, FFmpeg builds or all future advisories. Do not infer commercial rights in uploaded music from any software/model license.
